Sift

Sift is a private, single-user mail app. It sorts its owner's Gmail into a few custom inboxes (for example Bills, Travel or Newsletters) using rules the owner writes, and shows an unread count for each inbox so nothing gets missed.

It is not offered to the public. It runs on the owner's own phone and home computer and talks to Gmail directly through Google's API.

  • Reads message headers and, when a rule needs it, message text to decide which inbox an email belongs in.
  • Adds and removes Gmail labels so each email sits in exactly one inbox.
  • Never deletes mail, never sends mail on its own, and never shares mail with anyone.

Privacy policy

Sift is a personal project.
